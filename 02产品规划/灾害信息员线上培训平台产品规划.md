## 移动端已上线功能

### 登录与访问

**业务场景**：灾害信息员通过移动应急APP内H5进入平台，完成身份识别与会话建立。

**受众角色**：灾害信息员（移动端）、平台系统（统一登录与任务下发）。

**通用规则**：
- 仅灾害信息员可用，无游客模式、无注册功能。
- 统一登录成功后才可访问功能页面。
- 用户数据对接应急部灾害信息员用户数据库，按特定时间推送。
- 统一登录采用ticket机制，返回ticket、openUserId、用户名、手机号（含md5）。

**完整业务流程**：
```
移动应急APP进入H5 → 检测登录态 → 未登录则跳转统一登录平台 → 身份认证 → 匹配灾害信息员用户库 → 建立会话 → 进入首页
```

**详细流程步骤**：

1. **入口与登录**：移动应急APP → 灾害信息员线上培训平台入口 → H5加载 → 登录态检测 → 统一登录（ticket机制）→ 身份校验（openUserId匹配用户库）→ 会话建立

2. **异常情况**：会话过期自动重新登录；用户库无匹配记录时拒绝访问并提示；非灾害信息员不可使用

### 首页与学习

**业务场景**：登录后通过首页金刚区进入学习、考试、练习、竞赛功能，完成培训和能力提升。

**受众角色**：灾害信息员（移动端）。

**通用规则**：
- 金刚区入口由后台首页运营配置控制，按排序和上架状态展示。
- 学习进度实时更新，退出后保留进度。

**完整业务流程**：
```
登录 → 首页金刚区选择功能 → 课程学习/线上考试/答题练习/业务竞赛 → 结果沉淀到"我的"
```

**详细流程步骤**：

1. **首页金刚区**：6个功能入口（课程学习、线上考试、答题练习、业务竞赛、名师荟萃、政策专栏），由后台配置控制展示和排序。

2. **底部导航**：首页、学习、我的 三个Tab切换。

3. **课程学习**：课程浏览 → 按9大分类筛选（自然灾害/灾害预警/灾情统计/灾情报送/灾情台账/灾害救助/损失核算/名师讲堂/核查评估）→ 关键词搜索 → 课程详情 → 学习 → 学习记录。学习完成记录学习时长。

4. **答题练习**：专题列表 → 选择专题 → 答题页（逐题作答）→ 提交 → 查看结果（得分/用时/正确率）→ 答题记录查看。

5. **线上考试**：查看考试任务列表（待考试/已完成）→ 在规定时段内进入答题 → 倒计时作答 → 提交答卷 → 系统自动判分（客观题）。

6. **政策专栏与名师荟萃**：政策文件浏览、名师课程推荐。

### 竞赛与结果

**业务场景**：灾害信息员通过小程序/APP参与全国业务技能大赛，按初赛→复赛→决赛三阶段晋级，支持个人赛和团体赛双赛道。

**受众角色**：灾害信息员（参赛端）。

**通用规则**：
- 参赛人员为全国各级灾害信息员（以全国灾害信息员数据库登记备案为准）。
- 可同时参加个人赛和团体赛。
- 答题规则（三阶段通用）：每次20题，每题5分，满分100分，每题限时90秒。
- 答对得5分，答错/不答不得分；不可暂停、不可返回上一题、超时自动进入下一题。
- 复赛/决赛为异步比赛，匹配对手后各自独立完成，无需等待同时在线。
- 人员一旦确定，全赛程原则上不得更换。

**完整业务流程**：
```
进入竞赛 → 初赛（线上排名赛制·取最优成绩·前40%晋级）
                → 复赛（线上积分赛制·5天5轮胜3平1负0·前25%晋级 / 省级现场赛·分组循环）
                              → 决赛（线上淘汰赛制·3天3轮胜者晋级 / 省级现场赛·淘汰制）
                                            → 奖项评定
```

**详细流程步骤**：

1. **初赛参赛**：
   - 时段内（如8.25-8.29 6:00-24:00）进入，每人最多3次答题
   - 取最优成绩（最高分数+对应用时，分数相同取最短用时）
   - 个人按同级别（村/乡/县/市/省）在全省排名，前40%（含并列）晋级个人复赛
   - 县级团体：3名队员（县/乡/村各1名）平均分+平均用时，全省前40%晋级
   - 市级团体：4名队员（市/县/乡/村各1名）平均分+平均用时，全省前40%晋级
   - 省级团体：直接晋级复赛现场赛

2. **复赛参赛（线上）**：
   - 5天5轮，每日6:00系统自动匹配同级别对手
   - 个人：省级对省级、市级对市级...一对一匹配
   - 团体：队员按层级一对一匹配（县对县/乡对乡/村对村）
   - 参赛者在6:00-24:00内任意时间完成，无需等待对手
   - 积分规则：胜积3分/平各积1分/负积0分/未参赛判负0分/轮空判胜3分
   - 团体积分：队员积分累加（县级每日最高9分/市级每日最高12分）
   - 5轮累计积分排名：积分 > 平均答对题数 > 平均用时
   - 全国同级别前25%（含并列）晋级决赛
   - 省级团体复赛：32支队伍在山东/江西/四川/陕西4个分赛场进行现场分组循环赛

3. **决赛参赛（线上）**：
   - 3天3轮淘汰赛，每日匹配同级别对手
   - 每轮淘汰1/2参赛者，胜者晋级/败者淘汰
   - 第1天淘汰→未获奖 / 第2天淘汰→三等奖 / 第2天淘汰（2轮获胜被淘汰）→二等奖 / 第3天获胜→一等奖
   - 团体决赛：队员总分数/总用时累加判定胜负
   - 省级团体决赛：8支队伍在北京进行现场淘汰赛（四分之一决赛→半决赛→总决赛）

4. **竞赛结果查看**：各阶段成绩和排名、晋级状态追踪、省级现场赛赛程和结果查看。

**特殊场景**：
- 网络中断：答题中断后不可恢复，已答题目保留
- 轮空：参赛人数为奇数时自动判胜
- 特殊地区：无县级行政区/直辖市/兵团有独立组队和排名规则

### 我的与服务

**业务场景**：查看个人学习成果（证书/勋章）、账户信息和系统设置。

**受众角色**：灾害信息员（移动端）。

**通用规则**：证书、勋章无审批规则，达成条件自动获得。

**完整业务流程**：
```
点击"我的" → 个人信息 / 学习证书 / 我的勋章 / 系统设置 / 帮助中心 / 意见反馈
```

**详细流程步骤**：

1. **个人信息**：展示姓名、手机号、单位、等级（来源于应急部用户库，不可自行修改）。

2. **学习证书**：展示已获得的学习证书列表，可查看详情和保存。

3. **我的勋章**：展示已获得的勋章（由后台勋章管理配置，达成条件自动发放）。

4. **系统设置**：通知设置、关于平台等。

5. **帮助中心**：常见问题列表，问题分类浏览。

6. **意见反馈**：反馈内容填写（文字+可选图片），提交后流转至后台服务中心处理。

### 激励能力

**业务场景**：通过学习、练习、考试等行为获取积分，积分可用于商城兑换商品。

**受众角色**：灾害信息员（积分获取与兑换端）。

**通用规则**：兑换行为产生交易记录。

**完整业务流程**：
```
完成学习/练习/考试等行为 → 系统按积分规则自动发放积分 → 积分累计 → 选择商品 → 消耗积分 → 完成兑换 → 交易记录沉淀
```

**详细流程步骤**：

1. **积分获取**：行为触发后系统按规则自动发放，积分累计至用户账户。

2. **积分商城**：浏览商品列表 → 查看积分余额 → 选择商品 → 确认兑换（扣减积分）→ 交易记录。

## 后台已上线功能

### 首页运营配置

**业务场景**：运营人员配置移动端首页展示入口与内容。

**受众角色**：超级管理员/管理员（后台）。

**通用规则**：
- 首页入口支持上架/下架状态控制。
- 每项入口可维护名称、图标、排序、跳转去向。
- 配置变更后前台即时生效。

**完整业务流程**：
```
进入首页模块 → 查询配置项 → 新建/编辑 → 上下架 → 前台生效
```

**详细流程步骤**：

1. **金刚区管理**：列表查询、新建金刚区（名称/图标/排序/跳转去向/状态）、编辑、删除、上架/下架。下架入口前台不可见但保留配置。

2. **栏目管理**：栏目结构维护与状态管理，以树形结构展示栏目层级，支持新增子栏目、重命名、删除。

3. **展示管理**：首页展示内容配置与更新（Banner、推荐位、公告区等），设置展示顺序和上下架状态。

4. **专项入口配置**：答题练习入口配置（维护练习专题列表、控制上架状态和排序）、政策专栏入口配置（维护政策文章/文件列表、发布/编辑/下架）。

### 业务竞赛管理

**业务场景**：国家级/省级管理员组织业务技能大赛，配置三阶段赛程和双赛道规则，管理报名、人员、结果、统计和奖项。

**受众角色**：国家级管理员/省市县管理员（后台）、灾害信息员（参赛端）。

**大赛架构**：
- 三阶段：初赛（线上排名赛制）→ 复赛（线上积分赛制+省级现场赛）→ 决赛（线上淘汰赛制+省级现场赛）
- 双赛道：个人赛（村/乡/县/市/省四级）+ 团体赛（县3人/市4人/省5人三级）

**通用规则**：
- 竞赛支持多阶段赛程配置并按阶段执行。
- 报名、人员详情、结果、统计、导出、奖项为同域闭环。
- 答题规则三阶段通用：每次20题，每题5分，90秒限时，不可暂停/返回，超时自动下一题。
- 复赛/决赛为异步比赛，每日6:00自动匹配同级别对手。

**完整业务流程**：
```
创建竞赛 → 配置阶段（初赛/复赛/决赛）+赛道（个人/团体）→ 组织报名 → 人员参赛 → 自动匹配→ 排名/积分/淘汰判定 → 晋级 → 奖项评定 → 结果统计与导出
```

**详细流程步骤**：

1. **竞赛管理**：
   - 国家级/省级切换视图，竞赛列表查询
   - 新建竞赛：名称、层级、阶段配置、时间、关联题库
   - 编辑、删除、上架/下架（上架后移动端可见）
   - 进行中竞赛不可修改核心配置

2. **赛制配置**：
   - 初赛（排名赛制）：时段/每人次数上限(3次)/题数(20题)/分值(5分)/限时(90秒)/排名规则(分数>用时)/晋级比例(40%)
   - 复赛（积分赛制）：轮次(5天5轮)/匹配规则(同级别一对一/异步)/积分规则(胜3平1负0)/团体积分累加/晋级比例(25%)
   - 决赛（淘汰赛制）：轮次(3天3轮)/淘汰比例(1/2)/奖项关联(淘汰轮次→奖项等级)
   - 省级团体现场赛：分赛场/分组抽签/循环赛制/淘汰赛程

3. **匹配引擎**：每日6:00自动匹配同级别对手，异步比赛无需同时在线，团体队员按层级一对一匹配。

4. **题库管理（竞赛域）**：竞赛题库关联与维护，按阶段和赛道随机抽题。

5. **报名入口**：
   - 按国家级/省级及各级团体维度组织报名
   - 县级参赛队（3人：县/乡/村各1名）、市级参赛队（4人：市/县/乡/村各1名）、省级参赛队（5人：省/市/县/乡/村各1名）
   - 人员层级合规性校验（每级各1名，在灾害信息员数据库中）
   - 特殊地区规则：无县级行政区（中山/东莞等）无需组建县级队、直辖市（京津沪渝）无需组建市级队、兵团独立组队规则
   - 人员一旦确定全赛程原则上不得更换

6. **人员详情**：
   - 排名、姓名、手机号、等级、单位、答题次数、最优分数、最优用时
   - 复赛：每轮对手/分数/用时/积分/累计排名
   - 决赛：每轮结果/晋级淘汰/获奖等级

7. **竞赛结果**：按阶段（初赛/复赛/决赛）、赛道（个人/团体）、轮次、组别多维度查询，晋级状态追踪。

8. **奖项管理**：
   - 省级团体奖：冠军1名/亚军1名/季军1名/优胜奖5名
   - 市/县级团体奖：决赛排名全国前1/8→一等奖 / 前1/4→二等奖 / 前1/2→三等奖
   - 个人奖：同级别决赛排名全国前1/8→一等奖 / 前1/4→二等奖 / 前1/2→三等奖
   - 组织奖（县/市/省三级）：4项指标加权评定（参赛率/晋级率/复赛率/决赛入围），各级排名前5%获奖

9. **数据统计与导出**：竞赛统计看板与趋势展示（参赛率/晋级率/分数分布/组织奖指标），按赛事与数据类型导出人员名单、成绩单、排名、获奖名单、组织奖评分明细。

### 考试与题库

**业务场景**：管理员维护试卷库与题库，发布考试任务并查看统计结果。

**受众角色**：各级管理员（后台）、灾害信息员（考试执行）。

**通用规则**：
- 支持随机抽题。
- 不包含人脸校验逻辑。

**完整业务流程**：
```
维护试卷/题库 → 发布考试 → 学员作答 → 考试统计
```

**详细流程步骤**：

1. **试题资源**：试卷库/题库双页签管理。

2. **试卷管理**：
   - 新建试卷：填写试卷名称、考试时限、总分；设置组卷规则（各题型数量及分值：单选/多选/判断等）
   - 选择抽题模式：固定题目（手动选题）或 随机抽题（按题库/分类/难度抽取）
   - 状态管理：草稿 → 已发布 → 已关闭
   - 查看组卷规则

3. **题库管理**：
   - 题目列表（题型/分类/难度/分值），按分类/题型/难度筛选
   - 题目操作：新建、编辑、删除（被试卷引用的题目不可删除）
   - 批量操作：批量导入（Excel模板）、批量删除、批量修改分类/难度

4. **考试发布**：
   - 新建考试任务：选择关联试卷 → 设置考试时段 → 指定考试范围（全员/按机构/按人员）
   - 发布后学员移动端"线上考试"可见
   - 考试时段外不可进入答题

5. **随机抽题**：按题库/分类/难度设置抽题范围，设置各题型随机抽取数量，同一考试不同考生可获得不同题目组合。

6. **考试统计**：按考试任务查看参考人数、完成率、平均分、最高分、分数段分布图，支持按机构/人员维度查看和数据导出。

### 课程与资源管理

**业务场景**：维护课程素材资产与课程分类，提供资源批量运维能力，支撑课程内容高效运营。

**受众角色**：课程运营管理员。

**通用规则**：
- 资源支持分组管理与引用状态查询。
- 支持单条与批量操作。
- 已引用的资源不可删除。

**完整业务流程**：
```
资源上传/分组 → 资源维护 → 课程配置 → 分类管理 → 前台引用
```

**详细流程步骤**：

1. **资源库**：
   - 查询筛选：按名称、资源类型（视频/文档/图片/音频）、引用状态
   - 列表展示：资源名称、类型、大小、分组归属、引用数量、上传时间
   - 单条操作：上传、编辑（名称/描述/分组）、预览、删除、复制链接、转移分组

2. **分组管理**：新增分组、重命名、删除（非空分组提示先转移资源），以树形结构展示，资源必须归属至少一个分组。

3. **批量操作**：批量转移（选中资源转移至指定分组）、批量删除、批量导出。

4. **课程管理**：
   - 课程列表展示：名称、分类、讲师、时长、学习人数、状态
   - 课程编辑：名称、封面、分类（9大分类之一）、讲师、简介、关联资源（从资源库选择）
   - 课程结构：支持章→节→课时层级，每个课时关联具体资源
   - 状态管理：草稿 → 已发布 → 已下架
   - 课程必须关联至少一个资源方可发布

5. **分类管理**：课程分类体系维护（9大分类：自然灾害/灾害预警/灾情统计/灾情报送/灾情台账/灾害救助/损失核算/名师讲堂/核查评估），支持新增/编辑/排序/启用禁用。

**完整业务流程**：
```
积分获取 → 商品配置 → 兑换执行 → 交易留痕
```

**详细流程步骤**：

### 系统管理与治理

**业务场景**：维护后台账号权限、组织结构、日志审计和协议配置，保障系统稳定运行。

**受众角色**：超级管理员、系统管理员。

**通用规则**：
- 关键操作保留日志。
- 组织、角色、导航配置相互联动。
- 账号权限 = 所分配角色权限的并集，角色变更后实时生效。

**完整业务流程**：
```
账号与角色维护 → 导航管理 → 机构管理 → 日志审计 → 协议配置 → 人员导入
```

**详细流程步骤**：

1. **账号管理**：
   - 账号列表：姓名、手机号、关联角色、所属机构、创建时间、状态（启用/禁用）
   - 操作：新建（姓名/手机号/密码/角色/机构）、编辑（角色/机构/状态）、删除（逻辑删除）
   - 账号必须关联至少一个角色，禁用后不可登录后台

2. **角色管理**：
   - 角色列表：名称、关联账号数、权限概要
   - 角色编辑：权限配置 = 菜单权限（可见性）+ 操作权限（增删改查）+ 数据范围（全部/本省/本市/本县）
   - 角色关联账号时不可删除

3. **导航管理**：菜单层级结构维护，设置菜单名称/图标/排序/跳转路径，关联角色控制可见性。

4. **机构管理**：
   - 机构树：按国家→省→市→县→乡→村六级层级展示
   - 机构信息：机构名称、机构代码（唯一）、机构层级、父级机构、地址
   - 操作：新增子机构、编辑、删除（有子机构/用户时不可删除）

5. **日志管理**：
   - 操作日志：操作时间/操作人/操作类型/操作对象/操作结果/IP，支持按时间/操作人/操作类型筛选，不可删除和修改，支持导出
   - 异常日志：异常时间/异常类型/异常信息/影响范围，系统异常自动记录

6. **协议配置**：协议列表（名称/版本号/生效时间/状态），协议内容富文本编辑，版本管理，历史版本保留。

7. **人员数据导入**：下载导入模板 → 上传数据文件（Excel/CSV）→ 数据校验（格式/必填项/重复检测）→ 校验结果展示 → 确认导入，支持新增和更新两种模式，导入结果留痕。
