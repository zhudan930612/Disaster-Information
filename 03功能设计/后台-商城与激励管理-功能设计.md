## 功能单元 1：商品分类与商品管理

> 💡 **合并说明**: 本功能单元完成后,将"功能点描述"章节合并到 [06-商城与激励管理.md] 中。

### 功能概述

支持后台管理员维护积分商城的商品分类和商品信息，管理商品上架/下架状态，为学员提供积分兑换的实物或虚拟商品。

---

### 业务流程

#### 流程图

```
管理员进入"商城与激励管理"
      ↓
维护商品分类
      ↓
新建/编辑商品
      ↓
设置商品信息：名称、图片、积分价格、库存、兑换限制
      ↓
上架商品 → 移动端积分商城可见
      ↓
学员浏览商品 → 积分兑换
      ↓
交易记录沉淀
```

#### 业务规则

**触发条件**
- 管理员进入"商城与激励管理"

**处理逻辑**
1. 先维护商品分类体系，再在分类下新建商品
2. 商品信息包括：名称、图片、所需积分、库存数量、每人限兑次数
3. 上架后商品在移动端积分商城可见
4. 兑换成功后扣减积分、扣减库存

**边界情况**
- 商品库存为0：前台展示"已兑完"
- 积分不足：兑换按钮置灰
- 商品下架：已兑换记录保留
- ⚠ 待补充：是否支持虚拟商品（优惠券/权益类）

```
┌─────────────────────────────────────────────┐
│  商城与激励管理 > 商品管理                  │

│  ├ 数码   │ │ 状态:🟢上架  [编辑][下架] │  │
│  │ 产品   │ ├──────────────────────────┤  │
│  └ 其他   │ │ 🎧 蓝牙耳机              │  │
│            │ │ 积分:1500 库存:10       │  │
│ 分类管理  │ │ 状态:🔴下架  [编辑][上架] │  │
│ [+新增]   │ └──────────────────────────┘  │
└────────────┴────────────────────────────────┘
```

说明：左侧分类树+右侧商品列表，支持按分类筛选商品，操作路径清晰。

**方案 B：专题驱动式**

以专题为单位组织商品，适合活动型商城运营。

**方案 C：全列表式**

不带分类侧栏，所有商品平铺，通过筛选条件区分。

AI 推荐：A，理由：分类树+列表是商品管理的标准布局，支持按分类维度运营。

#### 商品分类管理

**入口路径**:
- 后台 → 商城与激励管理 → 商品分类

**页面名称**: "商品分类"页面

**页面功能**:

1. **分类列表**:
   - 展示分类名称、商品数量、排序
   - 支持新增、重命名、删除、排序

**业务规则**:
- 分类下有商品时不可删除

---

#### 商品管理

**入口路径**:
- 后台 → 商城与激励管理 → 商品管理

**页面名称**: "商品管理"页面

**页面功能**:

1. **商品列表**:
   - 展示商品名称、图片、积分价格、库存、状态
   - 支持按分类、状态筛选

2. **商品编辑**:
   - 商品名称（必填）
   - 商品图片（必填）
   - 所需积分（必填）
   - 库存数量（必填）
   - 每人限兑次数
   - 商品描述
   - 上架/下架状态

**业务规则**:
- 上架商品在移动端积分商城可见
- 库存为0时自动下架或标注"已兑完"

**待补充内容**:
1. 是否支持虚拟商品（优惠券/权益类）
2. 实物商品是否需要填写收货地址
3. 兑换后是否支持取消/退货

## 功能单元 2：专题管理与商城栏目

### 功能概述

支持管理员创建专题活动，将多个商品聚合展示；管理商城栏目的结构和内容，控制移动端积分商城的展示布局。

---

### 功能点描述

#### 专题管理

**入口路径**:
- 后台 → 商城与激励管理 → 专题管理

**页面名称**: "专题管理"页面

**页面功能**:

1. **专题列表**:
   - 展示专题名称、关联商品数量、有效期、状态
   - 支持新建、编辑、删除

2. **专题编辑**:
   - 专题名称、封面图、关联商品（多选）、有效期
   - 上架/下架状态

**业务规则**:
- 专题可将多个商品聚合展示
- 过期专题自动下架

---

#### 商城栏目管理

**入口路径**:
- 后台 → 商城与激励管理 → 商城栏目管理

**页面名称**: "商城栏目管理"页面

**页面功能**:

1. **栏目结构**:
   - 维护商城栏目层级和排序
   - 栏目可关联商品或专题

**业务规则**:
- 栏目配置后移动端积分商城即时生效

**待补充内容**:

2. 专题与栏目的关系

## 功能单元 3：交易记录与积分管理

### 功能概述

管理员查看积分兑换交易记录，跟踪兑换流水；维护积分获取规则，支撑积分获取与兑换的完整闭环。

---

### 功能点描述

#### 交易记录

**入口路径**:
- 后台 → 商城与激励管理 → 交易记录

**页面名称**: "交易记录"页面

**页面功能**:

1. **交易列表**:
   - 展示兑换时间、用户、商品、消耗积分、状态
   - 支持按时间、用户、商品、状态筛选

2. **交易详情**:
   - 查看兑换详情：商品信息、收货地址（如有）、物流信息（如有）

3. **数据导出**:
   - 导出交易记录

**业务规则**:
- 兑换交易记录自动生成，不可删除
- 交易记录与用户积分余额联动

---

#### 积分获取与兑换

**入口路径**:
- 后台 → 商城与激励管理 → 积分设置（或 用户管理 → 积分设置）

**页面功能**:

1. **积分规则配置**:
   - 设置积分获取规则：完成课程+N分、通过考试+N分、参与竞赛+N分等
   - 设置积分上限（日/周/月）

2. **积分兑换支撑**:
   - 兑换时扣减积分，记录流水

**业务规则**:
- 积分获取规则由后台维护
- 积分获取与兑换能力已上线

**待补充内容**:
1. 积分获取的具体行为规则清单和分值
2. 积分有效期和上限设置
3. 积分兑换的审批流程（如涉及高价值商品）
4. 当前功能状态：已实现但尚未测试验证和正式使用
