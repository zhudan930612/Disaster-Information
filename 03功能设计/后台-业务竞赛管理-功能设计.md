## 功能单元 1：竞赛管理

> 💡 **合并说明**: 本功能单元完成后,将"功能点描述"章节合并到 [03-业务竞赛管理.md] 中。

### 功能概述

支持国家级/省级管理员创建和配置业务技能大赛的全流程赛程，涵盖初赛、复赛、决赛三个阶段，个人赛与团体赛双赛道并行。竞赛通过"全国灾害信息员业务技能大赛"小程序或APP进行线上比赛，省级团体复赛/决赛为现场比赛。

### 业务流程

#### 流程图

```
管理员创建大赛
      ↓
配置大赛阶段：初赛 / 复赛 / 决赛
      ↓
配置各阶段赛制：排名赛制 / 积分赛制 / 淘汰赛制
      ↓
配置赛道：个人赛（基层/县/市/省） / 团体赛（县/市/省）
      ↓
组织报名（各级应急管理部门提交参赛队员名单）
      ↓
赛事进行中：
  ├─ 初赛：每人最多3次答题，取最优成绩排名，前40%晋级
  ├─ 复赛：5天5轮积分赛（线上），一对一匹配对决，前25%晋级
  └─ 决赛：3天3轮淘汰赛（线上），一对一匹配对决，逐轮淘汰
      ↓
省级团体复赛/决赛：现场比赛（分组循环赛 / 淘汰赛）
      ↓
奖项评定与公布
```

## 功能单元 2：初赛管理

### 功能概述

初赛为线上比赛，采用排名赛制，参赛人员在规定时段内最多可参加3次答题，取个人最优成绩进行排名。个人按同级别全省排名前40%晋级复赛，县级/市级团体按平均成绩全省排名前40%晋级复赛。

---

### 初赛配置规则

#### 基本参数

| 参数项 | 配置值 |
|--------|--------|
| 比赛时段 | 2025年8月25日－29日 6:00至24:00（示例） |
| 比赛形式 | 线上比赛（小程序/APP） |
| 赛制 | 排名赛制 |
| 每人答题次数上限 | 3次 |
| 每次题目数量 | 20道 |
| 每题分值 | 5分，满分100分 |
| 每题限时 | 90秒 |
| 答题规则 | 不可暂停、不可返回上一题、超时自动进入下一题 |
| 判分规则 | 答对得5分，答错/不答不得分 |

#### 个人初赛排名规则

```
每人最多3次答题
      ↓
取最优成绩 = 最高分数 + 对应用时（分数相同取最短用时）
      ↓
按村级/乡级/县级/市级/省级分别在全省排名
      ↓
排名规则：
  1. 分数高者在前
  2. 分数相同时，用时短者在前
      ↓
全省同级别前40%（含并列）晋级个人复赛
```

#### 县级团体初赛排名规则

```
3名队员（县级+乡级+村级各1名）各自最优成绩
      ↓
县级团体成绩 = 3人最优成绩的平均分 + 平均用时
      ↓
按县级在全省排名：
  1. 平均分高者在前
  2. 平均分相同时，平均用时短者在前
      ↓
全省县级前40%（含并列）晋级县级团体复赛
```

**特殊规则**：无县级行政区的地区（中山、东莞、儋州、三沙、嘉峪关）不进行县级团体赛排名。

**兵团规则**：县级参赛队由1名团级 + 2名连级灾害信息员组成。

#### 市级团体初赛排名规则

```
4名队员（市级+县级+乡级+村级各1名）各自最优成绩
      ↓
市级团体成绩 = 4人最优成绩的平均分 + 平均用时
      ↓
按市级在全省排名：
  1. 平均分高者在前
  2. 平均分相同时，平均用时短者在前
      ↓
全省市级前40%（含并列）晋级市级团体复赛
```

**特殊规则**：北京、天津、上海、重庆4个直辖市不进行初赛市级团体成绩排名。

**兵团规则**：市级参赛队由1名师级 + 1名团级 + 2名连级灾害信息员组成。

#### 省级团体初赛规则

省级团体初赛不单独进行，全国32支省级参赛队（31省+兵团）直接获得复赛现场比赛资格。

#### 初赛配置

**入口路径**:
- 后台 → 业务竞赛管理 → 竞赛管理 → 新建/编辑竞赛 → 初赛阶段

**页面名称**: "初赛配置"页面

**页面功能**:

   - 每人答题次数上限（默认3次）
   - 每次题目数量（默认20道）
   - 每题分值（默认5分）
   - 每题限时（默认90秒）

2. **排名规则配置**:
   - 成绩取值方式：取最优成绩（多次）/ 取最新成绩（单次）

   - 排名范围：全省 / 全国
   - 排序规则优先级：分数 > 用时

   - 晋级比例（默认40%）

## 功能单元 3：复赛管理

### 功能概述

复赛分为线上比赛和现场比赛两部分。个人、县级团体、市级团体为线上积分赛制（5天5轮），省级团体为现场分组循环赛制。线上比赛每日6:00自动匹配同级别对手进行一对一比赛。

---

### 复赛配置规则

#### 线上比赛（个人/县级团体/市级团体）

**基本参数**

| 参数项 | 配置值 |
|--------|--------|
| 比赛时段 | 个人+县/市团体：9月1日－5日 6:00至24:00（示例） |
| 比赛形式 | 线上比赛（小程序/APP） |
| 赛制 | 积分赛制 |
| 比赛轮次 | 5天5轮 |
| 每轮场次 | 个人：1场 / 县级团体：3场 / 市级团体：4场 |
| 每次题目数量 | 20道 |
| 每题分值 | 5分，满分100分 |
| 每题限时 | 90秒 |
| 答题规则 | 不可暂停、不可返回上一题、超时自动进入下一题 |

**匹配规则**

```
每日6:00 系统自动匹配
      ↓
个人赛：同级别一对一匹配（省级对省级、市级对市级...）
团体赛：同级别参赛队随机匹配，队员按层级一对一
      ↓
参赛者可在6:00-24:00任意时间比赛，无需等待对手
```

**积分规则**

| 比赛结果 | 积分 | 说明 |
|----------|------|------|
| 分数高（或同分用时短）→ 胜 | 积3分 | |
| 分数和用时均相同 → 平 | 各积1分 | |
| 分数低（或同分用时长）→ 负 | 积0分 | |
| 当日未参加 → 判负 | 积0分 | |
| 当日轮空 → 判胜 | 积3分 | |

**团体积分累加规则**：
- 县级团体每日积分 = 3名队员各自积分之和（最高9分/日，5轮最高45分）
- 市级团体每日积分 = 4名队员各自积分之和（最高12分/日，5轮最高60分）

**团体集体规则**：
- 当日集体未参加 → 判负积0分（县级）/ 0分（市级）
- 当日集体轮空 → 判胜积9分（县级）/ 12分（市级）

**复赛排名规则**

```
5轮结束，累计积分排名
      ↓
个人：按同级别全国排名
团体：按同级别全国排名
      ↓
排名规则：
  1. 累计积分高者在前
  2. 积分相同 → 平均答对题数多者在前
  3. 平均答对题数相同 → 平均答题用时短者在前
      ↓
全国同级别前25%（含并列）晋级决赛
```

#### 现场比赛（省级团体复赛）

**基本参数**

| 参数项 | 配置值 |
|--------|--------|
| 比赛时段 | 9月9日－11日（示例） |
| 参赛队伍 | 31省（区、市）+ 新疆生产建设兵团 = 32支省级参赛队 |
| 分赛场 | 山东、江西、四川、陕西 4个 |
| 分组方式 | 32支队伍抽签分8组，每组4支 |
| 赛制 | 分组循环赛制（组内每队与其他3队各赛1场） |

**省级参赛队组成**（5名）：
- 省级、市级、县级、乡级、村级灾害信息员各1名
- 北京/天津/上海/重庆：省级1 + 县级2 + 乡级1 + 村级1
- 兵团：省级1 + 师级1 + 团级1 + 连级2

**积分规则**：胜积3分、平各积1分、输积0分（小组内循环赛）

**晋级规则**：每组积分最高的1支队伍晋级决赛，积分相同取原始分数高者。8组共8支晋级。

## 功能单元 4：决赛管理

### 功能概述

决赛分为线上比赛和现场比赛。个人、县级团体、市级团体为线上淘汰赛制（3天3轮），省级团体为现场淘汰赛制。线上比赛每日6:00匹配对手，胜者晋级、败者淘汰。

---

### 决赛配置规则

#### 线上比赛（个人/县级团体/市级团体）

| 参数项 | 配置值 |
|--------|--------|
| 比赛时段 | 个人：9月15日－17日 / 团体：9月17日－19日 6:00至24:00（示例） |
| 比赛形式 | 线上比赛（小程序/APP） |
| 赛制 | 淘汰赛制 |
| 比赛轮次 | 3天3轮 |
| 每次题目数量 | 20道 |
| 每题分值 | 5分，满分100分 |
| 每题限时 | 90秒 |

**淘汰规则**

```
第1天 ──── 淘汰1/2参赛者 ──── 被淘汰
   │
   ├─ 胜者晋级
   │
第2天 ──── 淘汰1/2晋级者 ──── 被淘汰（获三等奖）
   │
   ├─ 胜者晋级
   │
第3天 ──── 淘汰1/2晋级者 ──── 被淘汰（获二等奖）
   │
   └─ 胜者（获一等奖）
```

**每轮判定**：
- 分数高（或同分用时短）→ 判胜，晋级下一轮
- 分数低（或同分用时长）→ 判负，直接淘汰
- 当日未参赛 → 判负，直接淘汰
- 当日轮空 → 判胜，晋级下一轮

**团体淘汰判定**：
- 县级团体：3名队员总分数/总用时累加，总分数高者晋级
- 市级团体：4名队员总分数/总用时累加，总分数高者晋级
- 总分数相同 → 总用时短者晋级

**奖项自动评定**：

| 被淘汰轮次 | 奖项 |
|------------|------|
| 第1天淘汰 | 三等奖 |
| 第2天淘汰 | 二等奖 |
| 第3天获胜 | 一等奖 |

#### 现场比赛（省级团体决赛）

**基本参数**

| 参数项 | 配置值 |
|--------|--------|
| 比赛时段 | 9月24日－25日（示例） |
| 比赛地点 | 北京 |
| 参赛队伍 | 8支省级参赛队 |
| 赛制 | 淘汰赛制（四分之一决赛→半决赛→总决赛） |

**赛程结构**：

```
四分之一决赛（4场）→ 4支被淘汰 → 优胜奖
      ↓
     4支晋级
      ↓
半决赛（2场）→ 2支被淘汰 → 季军赛
      ↓
     2支晋级 → 总决赛
      ↓
    冠军 / 亚军
```

**奖项对应**：
- 冠军1名、亚军1名、季军1名
- 优胜奖5名（进入决赛未获冠亚季军的省级参赛队）

3. 本市县级参赛队进入县级团体复赛的队伍数 / 本市县级行政区数
4. 本市参赛队是否进入市级团体决赛（进入=1，未进入=0）

**省级组织奖**（4项指标，权重各0.25）：
1. 本省参赛人数 / 本省全部灾害信息员人数
2. 本省参赛个人进入个人决赛的人数 / 本省参赛人数
3. 本省参赛队进入县级/市级团体决赛数 / 本省市级行政区数
4. 本省团体决赛成绩是否进入省级团体赛（进入=1，未进入=0）

   - 市级团体奖：一等奖/二等奖/三等奖 比例
   - 县级团体奖：一等奖/二等奖/三等奖 比例
   - 个人奖：按级别各设一等奖/二等奖/三等奖 比例
   - 组织奖：评定指标、权重、获奖比例

2. **自动评定规则**:
   - 团体奖/个人奖：根据决赛排名自动计算获奖名单
   - 组织奖：根据4项指标加权得分自动排名

3. **手动调整**:
   - 管理员可手动调整获奖名单
   - 支持批量导入/导出获奖名单

**业务规则**:
- 团体奖和个人奖在决赛结束后自动评定
- 组织奖在全部赛事结束后按指标计算
- 省级团体决赛现场赛奖项（冠亚季军）按现场结果确定

**待补充内容**:
