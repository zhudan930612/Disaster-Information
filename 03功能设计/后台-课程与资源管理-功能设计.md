## 功能单元 1：资源库管理

> 💡 **合并说明**: 本功能单元完成后,将"功能点描述"章节合并到 [05-课程与资源管理.md] 中。

### 功能概述

支持后台管理员统一管理课程素材资源（视频、文档、图片等），提供筛选、分组、批量操作能力，支撑课程内容高效运营。

---

### 业务流程

#### 流程图

```
管理员进入"课程与资源管理"
      ↓
选择"资源库"
      ↓
上传资源 / 查看已有资源
      ↓
按名称/类型/引用状态筛选
      ↓
对资源执行操作：编辑/预览/删除/复制链接/转移
      ↓
批量操作：批量转移/批量删除/批量导出
      ↓
资源可被课程引用
```

#### 业务规则

**触发条件**
- 管理员进入后台"课程与资源管理 → 资源库"

**处理逻辑**
1. 展示资源列表，支持按名称、资源类型、引用状态筛选
2. 单条资源操作：上传、编辑、预览、删除、复制链接、转移分组
3. 批量操作：批量转移、批量删除、批量导出
4. 资源被课程引用后，引用状态变更

**边界情况**
- 被课程引用的资源不可删除
- 删除分组前需确认组内资源已转移
- 大文件上传需进度展示
- ⚠ 待补充：支持的资源类型清单和文件大小上限

```
│ [+新建]   │ │ 类型:文档 大小:5MB      │  │
│ [重命名]  │ │ 未引用  [预览][编辑]... │  │
│ [删除]    │ └──────────────────────────┘  │
│            │                                │
│            │ [批量转移] [批量删除] [导出]   │
└────────────┴────────────────────────────────┘
```

说明：左侧分组树+右侧列表，分组间可拖拽转移资源，操作高效。

**方案 B：全列表式**

不带分组侧栏，所有资源平铺，通过筛选条件区分。

**方案 C：卡片预览式**

资源以缩略图卡片形式展示，支持网格/列表视图切换。

AI 推荐：A，理由：左侧分组+右侧列表是资源管理的经典布局，筛选和批量操作路径短，适合多类型资源的运营场景。

#### 资源库

**入口路径**:
- 后台 → 课程与资源管理 → 资源库

**页面名称**: "资源库"页面

**页面功能**:

1. **资源列表**:
   - 展示资源名称、类型、大小、引用状态、上传时间
   - 支持按名称、资源类型、引用状态筛选

2. **单条操作**:
   - 上传：选择文件上传至当前分组
   - 编辑：修改资源名称、描述、分组归属
   - 预览：在线预览资源内容（视频播放/文档查看/图片查看）
   - 删除：删除资源（已引用资源不可删除）
   - 复制链接：复制资源的访问链接
   - 转移：将资源转移至其他分组

3. **批量操作**:
   - 批量转移：选中多个资源转移至指定分组
   - 批量删除：选中多个资源批量删除
   - 批量导出：选中多个资源打包导出

**业务规则**:
- 已引用的资源不可删除，删除时提示"该资源已被X个课程引用"
- 资源类型由上传文件格式自动识别

**待补充内容**:
1. 支持的资源类型清单（视频/音频/文档/图片格式）
2. 单文件上传大小上限
3. 预览支持的文件格式范围

## 功能单元 2：资源分组管理

### 功能概述

管理资源的分组结构，支持新增、重命名、删除分组，将资源按分组归集，便于课程引用时快速定位。

---

### 业务流程

#### 流程图

```
管理员进入"资源库"
      ↓
在左侧分组区管理分组
      ↓
新增分组 → 命名 → 可拖入资源
重命名分组 → 选择分组 → 修改名称
删除分组 → 确认组内资源处理方式（转移/一并删除）
      ↓
资源归属分组，课程引用时可快速按分组筛选
```

#### 业务规则

**触发条件**
- 管理员进入资源库分组管理

**处理逻辑**
1. 分组以树形结构展示
2. 新增分组命名后即可使用
3. 删除分组需确认组内资源去向

**边界情况**
- 删除有资源的非空分组：提示先转移资源或一并删除
- ⚠ 待补充：分组层级深度上限

---

### 功能点描述

#### 资源分组

**入口路径**:
- 后台 → 课程与资源管理 → 资源库 → 左侧分组区

**页面名称**: 资源分组（资源库内嵌功能）

**页面功能**:

1. **分组树**:
   - 展示分组层级结构
   - 点击分组筛选右侧资源列表

2. **分组操作**:
   - 新增分组：在选中节点下新建子分组
   - 重命名：修改分组名称
   - 删除：删除空分组或强制删除（含资源）

3. **分组归集**:
   - 资源上传时选择目标分组
   - 支持资源跨分组转移

**业务规则**:
- 分组用于资源的分类管理
- 资源必须归属于至少一个分组

**待补充内容**:
1. 分组层级深度上限
2. 是否支持分组排序

## 功能单元 3：课程管理

### 功能概述

管理员维护课程内容，将资源组织为课程，设置课程属性（名称、分类、讲师、时长等），课程发布后在移动端"课程学习"中可见。

---

### 业务流程

#### 流程图

```
管理员进入"课程管理"
      ↓
查看课程列表
      ↓
新建课程 / 编辑已有课程
      ↓
填写课程信息（名称、分类、讲师等）
      ↓
关联资源（视频/文档等）
      ↓
设置课程结构（章/节/课时）
      ↓
发布课程 → 移动端可见
```

#### 业务规则

**触发条件**
- 管理员进入"课程管理"

**处理逻辑**
1. 列表展示所有课程，按分类和状态筛选
2. 新建课程需填写名称、选择分类（9大分类之一）、关联资源
3. 课程可设置章/节/课时结构
4. 发布后课程在移动端课程学习入口可见

**边界情况**
- 关联资源被删除：编辑课程时提示资源不可用
- 课程未关联任何资源时发布：校验并提示
- ⚠ 待补充：课程发布后是否可修改

---

### 功能点描述

#### 课程管理

**入口路径**:
- 后台 → 课程与资源管理 → 课程管理

**页面名称**: "课程管理"页面

**页面功能**:

1. **课程列表**:
   - 展示课程名称、分类、讲师、时长、学习人数、状态
   - 支持按分类和状态筛选

2. **课程编辑**:
   - 课程名称（必填）
   - 所属分类（9大分类之一，必填）
   - 课程封面（图片上传）
   - 讲师信息
   - 课程简介
   - 关联资源（从资源库选择）

3. **课程结构**:
   - 支持章节层级：课程 → 章 → 节 → 课时
   - 每个课时关联具体资源

4. **课程状态**:
   - 草稿 → 已发布 → 已下架

**业务规则**:
- 课程必须关联至少一个资源方可发布
- 课程分类使用9大分类体系
- 发布后课程在移动端即时可见

**待补充内容**:
1. 课程结构最大层级深度
2. 课程发布后是否可修改内容
3. 是否支持课程试看/预览
